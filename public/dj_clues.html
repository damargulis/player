GUESS THE ARTIST

5 rounds · 45 seconds each · the DJ describes, you name the band
The DJ describes a track in two or three sentences without naming anyone — you name the artist (3 pts). Enter to guess, unlimited tries, capitalization and punctuation ignored, and any one name in a shared credit counts. Answer fast for a speed bonus (+2 in the first 11s, +1 in the first 22s) and chain correct rounds for a streak bonus (up to +2).

Every clue is a live Messages API call, billed for real. A five-round game spends five of them; asking the DJ for a second angle costs a point and one more call. The next round's clue is written while you work on the current one, and the clock never starts before a clue is on screen.
